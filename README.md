# 🌦️ Weather App

A responsive Weather App built using **React** that fetches real-time weather data using a **Weather API**. The app provides accurate weather details and leverages **Material-UI** for enhanced UI components like cards, buttons, and icons.

---

## 📋 Features

- **Real-time Weather Data**: Displays near-perfect weather information for any city or location.
- **Search Functionality**: Search weather details by city name.
- **Weather Metrics**: Shows temperature, humidity, wind speed, and other weather details.
- **Responsive Design**: Mobile-friendly UI that works seamlessly across devices.
- **Material-UI Components**: Styled components for an intuitive and polished user interface.

---

## 🛠️ Tech Stack

- **React.js**: Frontend framework for building the user interface.
- **Material-UI**: For pre-styled components like cards, buttons, and icons.
- **Weather API**: Fetches real-time weather details.
